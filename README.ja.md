# GeminiForge

ウェブ版 Gemini（gemini.google.com）からパソコンを操作できるようにします。ファイルの読み書き、コマンドの実行、コードの作成、画面の確認、マウスとキーボードの操作ができます。
ウェブ版 Gemini の利用枠を使うので、API キーは不要です。

```
gemini.google.com  ──(Gemini がツール命令を出力)──▶  Chrome 拡張機能  ──▶  ローカルサーバー 127.0.0.1:18765
        ▲                                                              │ ファイル / PowerShell / スクリーンショット / マウスとキーボード
        └──────(結果とスクリーンショットを会話に貼り付けて送信)◀───────┘
```

## ダウンロード

[Releases](../../releases/latest) から `GeminiForge-<バージョン>-windows-x64.zip`（Windows） をダウンロードし、好きなフォルダーに展開します。ビルド済みのサーバー（`server\geminiforge-server.exe`）が入っているので、ほかにインストールするものはありません。初回実行時に Windows の SmartScreen 警告が出た場合は「詳細情報」→「実行」を選びます。

ソースからビルドする場合は [Rust](https://rustup.rs) をインストールしてください。`start.bat` が初回実行時に自動でビルドします（1 分ほど）。

Mac や Linux のコンピューターでは次の節を見てください。

## macOS と Linux

Chrome 拡張機能（方法 1）、MCP（方法 2）、ファイルとコマンドのツールは macOS と Linux でも使えます。Gemini は `screenshot` で画面を見られますが、マウス・キーボード操作は今のところ Windows だけです。GeminiForge が自動で Gemini に伝えます。

1. [Releases](../../releases/latest) からお使いのコンピューター用の zip をダウンロードして展開します：`macos-arm64`（Apple シリコン）、`macos-x64`（Intel Mac）、`linux-x64` または `linux-arm64`。
2. `.bat` ファイルの代わりに、ターミナルで `.sh` スクリプトを実行します：
   ```
   cd GeminiForge
   sh start.sh            # 方法 1：拡張機能用のサーバー
   sh start_mcp.sh        # 方法 2：MCP サーバー
   sh restore.sh          # バックアップを復元
   sh autostart_on.sh     # ログイン時に自動起動（autostart_off.sh で解除）
   ```
   使っている間はターミナルを開いたままにします。方法 1 と方法 2 のほかの手順は同じです。

- `run` は PowerShell ではなく bash を使います。
- **macOS**：初回起動時に「開発元を検証できないため開けません」と表示されることがあります。「システム設定」→「プライバシーとセキュリティ」で geminiforge-server の「このまま許可」をクリックし、もう一度起動してください。
- **Linux**：MCP の確認ウィンドウには `zenity`（または `kdialog`）、クリップボードのツールには `wl-clipboard`（Wayland）か `xclip`（X11）が必要です。例：`sudo apt install zenity wl-clipboard xclip`
- **スクリーンショット**：macOS では GeminiForge を起動するターミナルに画面収録を許可してください（「システム設定」→「プライバシーとセキュリティ」→「画面収録」）。Linux では `gnome-screenshot`、`grim`、`spectacle`、`scrot`、ImageMagick のどれかが必要です。
- 方法 2 の Tailscale トンネル：`tailscale funnel --bg --https=10000 http://127.0.0.1:18767`（Mac App Store 版のコマンドは `/Applications/Tailscale.app/Contents/MacOS/Tailscale`）。
- ソースからビルドする場合は [Rust](https://rustup.rs) をインストールしてください。`start.sh` が初回実行時に自動でビルドします。

## 方法 1：Chrome 拡張機能

### 初回設定

1. **ローカルサーバーを起動**：`start.bat` をダブルクリックします。黒いウィンドウは開いたままにしてください。閉じるとサーバーが止まります。
2. **Chrome 拡張機能をインストール**：
   1. Chrome のアドレスバーに `chrome://extensions` と入力します
   2. 右上の「デベロッパー モード」をオンにします
   3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダーの中の `extension` フォルダーを選びます
3. **Gemini を開く**：gemini.google.com を開きます（すでに開いている場合は再読み込みしてください）。右下に **⚒ GeminiForge** パネルが表示され、丸印が緑ならサーバーに接続済みです。
4. **初めてのスクリーンショットのアップロード**：パネルの「スクリーンショットをテスト」をクリックします。Gemini が画像やファイルからのコンテンツ作成についての同意画面を表示したら、同意してください（一度だけです）。テスト用のスクリーンショットが入力欄に入ったら、添付の ✕ をクリックして削除します。

### 使い方

Gemini で**新しいチャット**を開き、依頼内容を入力して送信します。例：「デスクトップに hello.py を作って実行して」。
拡張機能が最初のメッセージの先頭にツールの説明を自動で追加します（パネルの「新しいチャットにツールの説明を追加」にチェックが入っているとき）。

その後は、Gemini の回答に含まれるツール命令を拡張機能が検出し、実行モードに従って実行（または「実行」を押すまで待機）して、結果を自動で Gemini に返します。タスクが終わるまでこれを繰り返します。

すでに始まっているチャットで使うには、パネルの「ツールの説明を挿入」をクリックします。

右下の実行モードは、拡張機能の `gf_tool` JSON 命令だけを制御します。画面中央に「Let Gemini use … from GeminiForge」と「許可／拒否」が表示された場合、そのターンは MCP コネクタを使っています。拡張機能の「すべて自動実行」ではこの確認は省略されません。拡張機能モードを使うには、新しいチャットを作り、「チャット」モードを選び、`@GeminiForge` を付けず、「新しいチャットにツールの説明を追加」のチェックを入れたままにしてください。

**Gem でも使えます**：Gemini のサイドバーの Gem のページで新しい Gem を作り、`extension/prompts/ja.md`（または他の言語の `extension/prompts/<言語>.md`）の内容を「カスタム指示」に貼り付けます。その Gem の中のチャットでは、拡張機能は説明を重ねて追加しません。

**Pro または思考モデルがおすすめ**：複数ステップのタスク（コード作成、パソコン操作）では、Pro のほうが Flash よりずっと安定します。

## 方法 2：@ カスタムアプリ（MCP、おすすめ）

Gemini 公式のツール連携方法です。Gemini の入力欄に `@GeminiForge` と入力するだけで使えます。Chrome 拡張機能は不要で、Gemini のページが変わっても影響を受けず、同じくウェブ版の利用枠を使います。

```
gemini.google.com ──(MCP、OAuth 認証)──▶ https://<あなたの PC>.ts.net:10000 ──Tailscale Funnel──▶ 127.0.0.1:18767 (geminiforge-server.exe mcp)
```

### 初回設定

1. **MCP サーバーを起動**：`start_mcp.bat` をダブルクリックします。ウィンドウに **MCP URL** と **ペアリングコード** が表示されます。開いたままにしてください。
2. **公開トンネルを開く**（一度だけ）：PowerShell で次を実行します
   ```
   & "C:\Program Files\Tailscale\tailscale.exe" funnel --bg --https=10000 http://127.0.0.1:18767
   ```
   Funnel がこのパソコンの公開 URL を表示します。その URL の末尾に `/mcp` を付けたものがコネクタの URL です。例：`https://<デバイス名>.<tailnet>.ts.net:10000/mcp`。自分の URL を使ってください。トンネルを閉じるには：
   ```
   & "C:\Program Files\Tailscale\tailscale.exe" funnel --https=10000 off
   ```
   Tailscale がない場合は [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) をインストールし、`server/mcp_config.json` の `"tunnel"` を `"cloudflared"` にします。MCP サーバーが自分でクイックトンネルを開き、その URL を表示します。この URL はサーバーを起動するたびに変わるので、起動のたびに新しい URL を Gemini のカスタムアプリに入力し、もう一度ペアリングしてください。
3. **Gemini に追加**：Gemini の入力欄に `@` を入力 → すべてのコネクタを表示 → カスタムアプリを作成 → MCP URL を貼り付け → 続行。
   - 「その他の設定」のクライアント ID／シークレットは、まず空欄で構いません。Gemini に入力を求められたら、`server/mcp_config.json` の `client_id` と `client_secret` を入力してください。
4. **GeminiForge に接続** のページが表示されたら、サーバーのウィンドウに出ている **ペアリングコード** を入力し、「接続を許可」をクリックします。

### 使う

1. Gemini を開きます。どちらでも構いません：
   - **Gemini デスクトップアプリ**（Windows）：英語以外の UI の「チャット」モードでもそのまま使えます。`@` メニューに GeminiForge が表示され、英語 UI や「タスク」モードに切り替える必要はありません（2026-11-23、アプリ 1.21.1 で確認）。デスクトップアプリで使えるのはこの方法だけで、方法 1 の Chrome 拡張機能はデスクトップアプリに読み込めません。
   - **ウェブ版**：**英語 UI** の `https://gemini.google.com/app?hl=en` を使います。英語 UI では通常のチャット（Chat）で @GeminiForge が使え、@ を付けなくても自動で呼び出されます。
     英語以外の UI の「チャット」モードでは @ メニューにカスタムアプリが表示されず、「**タスク**」モードに切り替える必要があります（2026-11 に確認）。
2. `@` を入力してメニューから **GeminiForge** を選び、依頼内容を入力します。例：「デスクトップにあるファイルを一覧にして」。

何かを変更する操作では、**まず Gemini のページが**「Let Gemini use … from GeminiForge」と確認します。「許可」を押すと実行されます。

続いて、サーバーがパソコン上に**2 つ目の確認ウィンドウ**を表示します（`approval` が既定の `readonly` のとき）：
- **許可**：今回だけ許可
- **このツールを30分間許可**：同じ種類の操作は再確認しません
- **拒否**、または 45 秒間操作がなければ自動で拒否（Gemini は 1 分ほどであきらめます）

確認モードは `server/mcp_config.json` の `approval` を変更してサーバーを再起動すると切り替わります：`readonly`（既定：Gemini のページでの確認 + パソコンの確認ウィンドウ）、`all`（読み取り専用の操作でもウィンドウを表示）、`none`（Gemini のページでの確認だけで、パソコンのウィンドウは表示しない）。

### セキュリティ

- 接続にはペアリングコードの入力が必要です。5 回間違えると 10 分間ロックされます。
- `server/mcp_config.json`（ペアリングコード、シークレット）と `server/mcp_auth.json`（ログイン情報）は他人に渡さないでください。
- 接続済みのデバイスをすべて無効にするには、サーバーを止め、`server/mcp_auth.json` を削除して、もう一度起動します。ペアリングコードを変えるには、`mcp_config.json` の `pairing_code` の行を削除して再起動します。
- トンネルを開くと誰でもこの URL に到達できますが、ペアリングコードがなければツールは一切使えません。

## パネルの説明

Gemini のページ右下の **⚒ GeminiForge** を展開し、「言語」メニューで **English、繁體中文、简体中文、日本語、한국어** を切り替えます。初回は Chrome の表示言語に合わせ、それ以外の言語では英語になります。選択は現在の Chrome プロファイルに保存され、開いている Gemini のタブにも反映されます。

パネル、確認ボタン、その後に挿入するツールの説明は、すべて選んだ言語になります。ローカルサーバーに接続すると、次に開く MCP のペアリングページとデスクトップの確認ウィンドウにも反映されます。既存のインストールを更新するときは、拡張機能を再読み込みし、Gemini のタブを再読み込みして、`start.bat` のローカルサーバーを再起動してください。MCP も使っている場合は、`start_mcp.bat` も再起動してください。

| 項目 | 役割 |
|---|---|
| 丸印 | 緑：サーバーに接続済み。赤：`start.bat` を実行してください |
| 有効にする | オフにすると、拡張機能はツールを一切実行しません |
| 新しいチャットにツールの説明を追加 | 新しいチャットで最初のメッセージを送るとき、先頭にツールの説明を自動で追加します |
| 回答が終わったら通知 | Gemini の回答が終わったとき（またはツールのタスク全体が終わったとき）、「実行」を押すのを待っているとき、エラーが起きたときに Windows の通知を表示します。通知をクリックするとその Gemini のタブに戻ります。既定の「タブを離れているときだけ」では、別のタブやアプリを見ているときだけ通知し、Gemini のタブを見ているときは通知しません。「常に通知」はタブを見ていても通知し、「オフ」は一切通知しません。隣の「通知をテスト」はすぐに通知を 1 件送り、Windows にブロックされていないか確認できます。通知を送るたびにパネルのログに 🔔 の行が増えます。「有効にする」にもチェックが必要です |
| 実行モード | **毎回確認する**：最も安全<br>**読み取り専用ツール以外は確認**（既定）：ファイルの閲覧とスクリーンショットは自動で実行。ファイルの書き込み、コマンドの実行、クリックは「実行」を押す必要があります<br>**すべて自動実行**：完全に任せます。信頼できるタスクでだけ使ってください |
| 停止 | 実行中の処理をすぐに中止します |
| 確認ボックスの「このチャットで許可」 | 同じチャットでは、このツールを再確認しません（チャットを変えるとリセット） |
| スクリーンショットをテスト | スクリーンショットとアップロードが正常か確認します |

自動実行が 200 回続くと、いったん止まって続けるかどうかを確認します。

通知が表示されないとき：Windows の「設定 → システム → 通知」で **Google Chrome** の通知がオンになっていることを確認し、「応答不可」をオフにします。拡張機能を更新したばかりの場合は、`chrome://extensions` で GeminiForge の再読み込み（↻）をクリックすると、拡張機能が通知の権限を取得します。Gemini のタブがバックグラウンドで 5 分を超えると、Chrome がチェックの頻度を下げるため、通知が 1 分ほど遅れることがあります。

## Windows 起動時に自動起動（任意）

- `autostart_on.bat` をダブルクリック：以後、起動時にサーバーが最小化ウィンドウで自動的に起動します
- `autostart_off.bat` をダブルクリック：解除します

## Gemini が使えるツール

- **ファイルとプログラム**：cd、list_dir、read_file、read_files、write_file、edit_file、edit_files、search、find_files、run（PowerShell）、job_status、stop_job、start_process、open、クリップボード
- **バックアップと復元**：list_backups、restore_backup（下の「ファイルのバックアップ」を参照）
- **パソコンの操作**：screenshot、zoom（小さい文字を拡大）、click、double_click、right_click、move、drag、type、key、scroll（`window_id` での指定、`percent` でのジャンプ、内側のコンテナーを UIA で自動スクロールする補助に対応）
- **正確なクリックと読み取り**：list_windows、focus_window、ui_elements（ボタン／リンクと、入力欄の値やチェック状態を一覧表示）、read_window（ウィンドウやウェブページの主な内容のテキストと入力値を、スクロール領域の下の部分も含めて一度に読み取り）、click_element（名前または番号でクリック。画面外の要素は自動で表示範囲にスクロールし、ウィンドウのテキストを報告）、type_element（入力欄へのフォーカス、クリア、入力、読み戻しての確認を一度に実行）

`ui_elements` は `window_id` を返します。以降の操作で同じ ID を渡すと、同じ名前のブラウザータブを選んでしまうのを防げます。すでに確認した一連のボタンは `click_elements {window_id, names}` で順番に実行できます（最大 16 個）。途中で失敗するとそこで止まります。MCP モードでは、この一連の操作全体を Gemini のページが確認します。ページ側の確認が省略されるわけではありません。ウィンドウや要素が無効になった場合、ツールはエラーを返して再確認を求め、古い座標でクリックすることはありません。

日本語のツールの説明は `extension/prompts/ja.md` に、他の言語は `extension/prompts/` にあり、自由に編集できます。

## ファイルのバックアップ

Gemini が `write_file` または `edit_file` でファイルを変更するたびに、先に元のファイルを `GeminiForge/backups/` にコピーし、結果にバックアップ番号を添えます。

- **Gemini に復元を頼む**：「さっき変更したファイルを元に戻して」と伝えると、`list_backups` で番号を探し、`restore_backup` で復元します。
- **自分で復元する**：`restore.bat` をダブルクリックすると、直近 30 件のバックアップが表示されます。番号を入力して Enter を押します。
- 元は存在せず Gemini が新しく作ったファイルは、復元すると削除されます。
- 復元の前にも現在の内容をバックアップするので、復元を間違えてもさらに元に戻せます。
- 30 日間、最大 5000 件を保持します。50 MB を超えるファイルは記録だけで、内容はバックアップしません。
- **`run` で実行したコマンドが変更したファイルはバックアップされません**（PowerShell でのファイル削除、`git checkout` など）。

## ヒント

- **自分もパソコンを使っているとき**：click、type、key は実際のマウスとキーボードを使うので、操作がぶつかることがあります。click_element はほとんどのボタンを直接作動させるので、邪魔になりません。
- **マルチモニター**：スクリーンショットは既定でマウスのあるモニターを撮影します。要素をクリックしたりウィンドウを切り替えたりした後は、そのウィンドウのあるモニターを自動で撮影します。

## 安全上の注意

- **マウス操作の緊急停止**：マウスを画面のいずれかの隅へ勢いよく動かすと、実行中の操作がすぐに中止されます。
- Gemini は見たウェブページやファイルの内容を読みます。そこに悪意のある指示が隠れている可能性があります。「すべて自動実行」を使うときは特に注意してください。
- サーバーはこのパソコンの Chrome 拡張機能からのリクエストだけを受け付けます。通常のウェブページからは呼び出せません。
- 読み取ったファイルとスクリーンショットの内容は Google の Gemini に送信されます。

## フォルダー構成

```
GeminiForge/
├─ start.bat              拡張機能用のサーバーを起動（方法 1）
├─ start_mcp.bat          MCP サーバーを起動（方法 2）
├─ autostart_on.bat       Windows 起動時の自動起動を設定
├─ autostart_off.bat      Windows 起動時の自動起動を解除
├─ restore.bat            バックアップを一覧表示してファイルを復元
├─ *.sh                   macOS と Linux 用の同名スクリプト（start.sh など）
├─ backups/               自動バックアップ（git には入れない）
├─ server/               ローカルサーバー（Rust。拡張機能と MCP で同じプログラム）
│  ├─ src/                すべてのツール、拡張機能用サーバー、MCP サーバー、確認ウィンドウ、バックアップ
│  ├─ tests/
│  ├─ Cargo.toml
│  ├─ exe.cmd             サーバープログラムを探し、初回は自動でビルド
│  ├─ lang.cmd            バッチファイル共通の多言語メッセージ
│  └─ README.md           ビルド、環境変数、高速待機などの詳細
└─ extension/             Chrome 拡張機能
   ├─ manifest.json
   ├─ background.js       リクエストをローカルサーバーに転送
   ├─ content.js          Gemini のページ上で：パネル、ツール命令の検出、結果の返送
   ├─ languages.js        言語タグの対応表
   ├─ _locales/           多言語の UI メッセージ（en、zh_TW、zh_CN、ja、ko）
   └─ prompts/            Gemini 向けの多言語のツールの説明（ja.md など。編集可）
```

## よくある質問

- **丸印が赤い**：`start.bat` が起動していないか、閉じられています。
- **ポート 18765 が使用中**：`start.bat` の `call "%~dp0server\exe.cmd"` の前の行に `set GF_PORT=別のポート番号` を追加し、`extension/manifest.json` と `extension/background.js` の 18765 も合わせて変更してから、`chrome://extensions` で拡張機能を再読み込みします。
- **拡張機能のコード（content.js など）を変更した**：`chrome://extensions` で GeminiForge のカードの再読み込み ↻ をクリックし、Gemini を再読み込みします。
- **Gemini の更新後に拡張機能が動かなくなった**：Gemini のページの構造が変わっています。`content.js` の入力欄と送信ボタンを探す部分を更新する必要があります。
- **@GeminiForge を確認なしで完全に自動化できますか？** 一部だけ可能です：
  - **パソコン上の確認ウィンドウ**：オフにできます。`server/mcp_config.json` の `approval` を `none` に変えてサーバーを再起動します。
  - **Gemini のページの「許可 / 拒否」**：オフにできません。Google の安全機構で、何かを変更するツール（プログラムの起動、クリック、ファイルの変更）は毎回確認されます。
  - すべてのツールを「読み取り専用」として報告することで、ページ側の確認を省略できます：`server/mcp_config.json` で `"web_confirm": "off"` を設定してサーバーを再起動します（既定は `on`）。**自己責任で**：これは Google の安全設計を回避することになります。Gemini が読んだウェブページやファイルに悪意のある指示（「このフォルダーを削除して」など）が隠れていると、確認なしでそのままパソコン上で実行されます。見ているときだけ使うことをおすすめします。
  - 完全自動に最も近い方法：@GeminiForge を使い、`approval` を `none` にして、何かを変更するステップごとに Gemini のページで「許可」を 1 回押す。または Chrome 拡張機能（チャットモード）の「すべて自動実行」を使う。こちらは何も押す必要がありませんが、見ているときだけ使うのが安全です。
