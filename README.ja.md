# GeminiForge

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

Turn Gemini Web into a local computer agent — files, terminal, and desktop control.

Web 版 Gemini（gemini.google.com）からあなたのパソコンを操作できるようにします。ファイルの読み書き、コマンドの実行、プログラムの作成、画面の確認、マウスとキーボードの操作が可能です。
Web 版 Gemini の利用枠を使うため、API キーは不要です。

## 動作環境

- Windows 10 / 11
- Python 3.10 以上（インストール時に「Add Python to PATH」にチェック）
- ログインして使える Gemini アカウント
- Chrome 拡張機能モードには Google Chrome が必要です。MCP モードには Tailscale のインストールとログインが必要で、アカウントで Funnel が使えることが条件です

本プロジェクトをダウンロードしたら、フォルダ全体を固定の場所に展開し、以下のいずれかの方法で設定してください。

拡張機能パネル、デスクトップの確認ポップアップ、サーバーのウィンドウ、.bat スクリプトは、拡張機能パネルで選んだ言語で表示されます（既定は Windows の表示言語）。

```
gemini.google.com  ──(Gemini がツールコマンドを出力)──▶  Chrome 拡張機能  ──▶  ローカルサーバー 127.0.0.1:18765
        ▲                                                              │ ファイル読み書き / PowerShell / スクリーンショット / マウス・キーボード
        └──────────────(結果とスクリーンショットを会話に自動で貼り付けて送信)◀──────────────────┘
```

## 方法 1：Chrome 拡張機能

### 初回設定

1. **ローカルサーバーを起動**：`start.bat` をダブルクリックします。初回は必要なパッケージが自動でインストールされます。黒いウィンドウは開いたままにしてください。閉じるとサーバーが止まります。
2. **Chrome 拡張機能をインストール**：
   1. Chrome のアドレスバーに `chrome://extensions` と入力
   2. 右上の「デベロッパー モード」をオン
   3. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ内の `extension` フォルダを選択
3. **Gemini を開く**：gemini.google.com を開きます（すでに開いている場合は再読み込み）。右下に **⚒ GeminiForge** パネルが表示され、丸印が緑になればサーバーに接続済みです。
4. **初回のスクリーンショットアップロード**：パネルの「スクリーンショットをテスト」をクリックします。画像やファイルからのコンテンツ作成に関する同意ダイアログが Gemini に表示されたら、同意してください（1 回だけ）。テスト用のスクリーンショットが入力欄に入ったら、添付ファイルの ✕ で削除して構いません。

### 使い方

Gemini で**新しいチャット**を開き、やりたいことを入力して送信するだけです。例：「デスクトップに hello.py を作って実行して」。
拡張機能が最初のメッセージの先頭にツールの説明を自動で追加します（パネルの「新しいチャットにツールの説明を追加」にチェックが入っている場合）。

その後、Gemini の返信に含まれるツールコマンドを拡張機能が検出し、モードに従って実行（または「実行」がクリックされるのを待機）し、結果を自動で Gemini に返します。これをタスクが完了するまで繰り返します。

すでに始まっているチャットで使いたい場合は、パネルの「ツールの説明を挿入」をクリックしてください。

右下の実行モードが制御するのは、拡張機能の `gf_tool` JSON コマンドだけです。画面中央に「Let Gemini use … from GeminiForge」と「Allow / Deny」が表示された場合、そのターンは MCP コネクタを使っています。拡張機能の「すべて自動実行」ではこの確認はなくなりません。拡張機能モードを使うには、新しいチャットを作成して Chat モードを選び、`@GeminiForge` を付けず、「新しいチャットにツールの説明を追加」にチェックを入れたままにしてください。

**Gem でも使えます**：Gemini 左側の Gem manager で新しい Gem を作成し、`extension/prompts/ja.md` の内容を Instructions に貼り付けます。その Gem 内のチャットでは、拡張機能が説明を重ねて追加することはありません。

**Pro または「思考型」モデルがおすすめです**：複数ステップのタスク（プログラム作成、パソコン操作）では、Pro のほうが Flash よりずっと安定します。

## 方法 2：@ カスタムアプリ（MCP、おすすめ）

Gemini のカスタムアプリで MCP に接続し、入力欄で `@GeminiForge` を選ぶだけで使えます。Chrome 拡張機能は不要で、こちらも Web 版の利用枠を使います。カスタムアプリが使えるかどうかは、Gemini のアカウント、表示言語、モードによって異なります。

```
gemini.google.com ──(MCP、OAuth 認証)──▶ https://<あなたのPC>.ts.net:10000 ──Tailscale Funnel──▶ 127.0.0.1:18766 (mcp_server.py)
```

### 初回設定

1. **MCP サーバーを起動**：`start_mcp.bat` をダブルクリックします。ウィンドウに **MCP URL** と **ペアリングコード** が表示されます。開いたままにしてください。
2. **公開トンネルを開く**（1 回だけ）：PowerShell で次を実行
   ```
   & "C:\Program Files\Tailscale\tailscale.exe" funnel --bg --https=10000 http://127.0.0.1:18766
   ```
   Funnel にこのパソコンの公開 URL が表示されます。その末尾に `/mcp` を付けたものがコネクタの URL です。例：`https://<デバイス名>.<tailnet>.ts.net:10000/mcp`。必ずご自身の URL を使ってください。トンネルを閉じるには：
   ```
   & "C:\Program Files\Tailscale\tailscale.exe" funnel --https=10000 off
   ```
3. **Gemini に追加**：Gemini の入力欄で `@` を入力 → すべてのコネクタを表示 → カスタムアプリを作成 → MCP URL を貼り付け → 続行。
   - 追加設定のクライアント ID／シークレットは、最初は空欄のままで構いません。Gemini から入力を求められたら、`server/mcp_config.json` の `client_id` と `client_secret` を入力してください。
4. **GeminiForge に接続** ページが表示されたら、サーバーのウィンドウに表示された **ペアリングコード** を入力し、「接続を許可」をクリックします。

### 使い方

1. **英語 UI** で Gemini を開きます：`https://gemini.google.com/app?hl=en`（または Gemini デスクトップアプリ）。英語 UI では通常のチャット（Chat）で @GeminiForge が使え、@ を入力しなくても自動で呼び出されることがあります。
   中国語 UI の「對話」（Chat）モードでは @ メニューにカスタムアプリが表示されず、「**任務**」モードに切り替えた場合のみ使えます（2026-11 時点で確認）。
2. `@` を入力してメニューから **GeminiForge** を選び、続けてやりたいことを入力します。例：「デスクトップのファイルを一覧表示して」。

何かを変更する操作では、**まず Gemini の Web ページで 1 回確認されます**（「Let Gemini use … from GeminiForge」）。「Allow」をクリックすると実行されます。

続いて、サーバーがあなたのパソコン上に**2 つ目の確認ウィンドウ**を表示します（`approval` が既定の `readonly` の場合）：
- **許可**：今回だけ許可
- **このツールを30分間許可**：以後、同じ種類の操作では確認しない
- **拒否**、または 45 秒間操作がなければ自動で拒否（Gemini は 1 分ほど待つとあきらめます）

確認モードは `server/mcp_config.json` の `approval` を変更してサーバーを再起動すると切り替えられます：`readonly`（既定：Gemini Web の確認 + パソコンの確認ウィンドウ）、`all`（読み取り専用の操作でもウィンドウを表示）、`none`（Gemini Web の確認のみで、パソコンのウィンドウは表示しない）。

### セキュリティ

- 接続にはペアリングコードの入力が必要です。5 回間違えると 10 分間ロックされます。
- `server/mcp_config.json`（ペアリングコード、シークレット）と `server/mcp_auth.json`（ログイン資格情報）は他人と共有しないでください。
- 接続済みのすべてのデバイスを無効にするには：サーバーを停止し、`server/mcp_auth.json` を削除してから再起動します。ペアリングコードを変更するには：`mcp_config.json` の `pairing_code` の行を削除して再起動します。
- トンネルを開くと誰でもその URL にアクセスできますが、ペアリングコードがなければどのツールも使えません。

## パネルの説明

Gemini ページ右下の **⚒ GeminiForge** を展開し、「言語」メニューで **English、繁體中文、简体中文、日本語、한국어** を切り替えます。初めて開いたときは Chrome の表示言語に従い、それ以外の言語の場合は英語が既定になります。選択は現在の Chrome プロファイルに保存され、開いている Gemini タブにも同期されます。

パネル、確認ボタン、その後に挿入されるツールの説明は、選んだ言語で表示されます。ローカルサーバーに接続すると、次に開く MCP ペアリングページとデスクトップの確認ウィンドウにもこの設定が適用されます。既存のインストールを更新するときは、拡張機能を再読み込みし、Gemini タブを再読み込みして、`start.bat` のローカルサーバーを再起動してください。MCP も使っている場合は、`start_mcp.bat` も再起動してください。

| 項目 | 機能 |
|---|---|
| 丸印 | 緑：サーバー接続済み、赤：`start.bat` を実行してください |
| 有効にする | オフにすると拡張機能はツールを一切実行しません |
| 新しいチャットにツールの説明を追加 | 新しいチャットで最初のメッセージを送るとき、ツールの説明を自動で先頭に追加します |
| モード | **毎回確認する**：最も安全<br>**読み取り専用ツール以外は確認**（既定）：ファイルの閲覧やスクリーンショットは自動実行、ファイルの書き込み、コマンドの実行、マウスクリックは「実行」のクリックが必要<br>**すべて自動実行**：完全におまかせ。信頼できるタスクでのみ使ってください |
| 停止 | 現在の処理をすぐに中止します |
| 確認ボックスの「このチャットで許可」 | 同じチャット内では、このツールについて以後確認しません（チャットを変えるとリセット） |
| スクリーンショットをテスト | スクリーンショットとアップロードが正常に動くか確認します |

自動実行が 40 ラウンド続くと、いったん止まって続行するかどうかを確認します。

## 起動時に自動で開始（任意）

- `autostart_on.bat` をダブルクリック：以後、パソコン起動時にサーバーが最小化ウィンドウで自動起動します
- `autostart_off.bat` をダブルクリック：解除

## Gemini が使えるツール

- **ファイルとプログラム**：list_dir、read_file、write_file、edit_file、search、find_files、run（PowerShell）、start_process、open、クリップボード
- **バックアップと復元**：list_backups、restore_backup（下記「ファイルのバックアップ」を参照）
- **パソコン操作**：screenshot、zoom（小さな文字を拡大）、click、double_click、right_click、move、drag、type、key、scroll
- **正確なクリック**：list_windows、focus_window、ui_elements（Windows のアクセシビリティ機能でボタンやリンクの名前と位置を一覧表示）、click_element（名前または番号でクリックし、ボタンを直接実行します。マウスを動かさず、ウィンドウがバックグラウンドでも動作し、ウィンドウに表示されているテキストを返します）

`ui_elements` は `window_id` を返します。以降の操作で同じ ID を指定すれば、同じ名前のブラウザタブを誤って選ぶのを防げます。確認済みの一連のボタンは `click_elements {window_id, names}` で順番に実行できます（最大 16 個）。どこかのステップで失敗するとそこで止まります。MCP モードでは、この一連の操作全体について引き続き Gemini の Web ページで確認が行われ、Web 側の確認がなくなるわけではありません。ウィンドウや要素が無効になった場合、ツールはエラーを返して再確認を求め、古い座標でクリックすることはありません。

ツールの説明は `extension/prompts/` にあり、言語ごとに 1 ファイルです。自由に編集できます。

## ファイルのバックアップ

Gemini が `write_file` または `edit_file` でファイルを変更する前に、元のファイルを `GeminiForge/backups/` にコピーし、結果にバックアップ番号を添えます。

- **Gemini に復元してもらう**：「さっき変更したファイルを元に戻して」と伝えれば、`list_backups` で番号を探し、`restore_backup` で復元します。
- **自分で復元する**：`restore.bat` をダブルクリックすると最近 30 件のバックアップが表示されます。番号を入力して Enter を押すだけです。
- もともと存在せず Gemini が新しく作ったファイルは、復元すると削除されます。
- 復元の前に現在の内容もバックアップされるので、復元を間違えても元に戻せます。
- 保存期間は 30 日、最大 5000 件です。50 MB を超えるファイルは記録のみで、内容はバックアップされません。
- **`run` で実行したコマンドによって変更されたファイルはバックアップされません**（例：PowerShell でのファイル削除、`git checkout`）。

## ちょっとした注意

- **あなたもパソコンを使っているとき**：click、type、key は実際のマウスとキーボードを使うため、あなたの操作とぶつかることがあります。click_element はほとんどのボタンを直接実行するので、邪魔になりません。
- **マルチモニター**：スクリーンショットは既定でマウスのあるモニターを撮影します。要素をクリックしたりウィンドウを切り替えたりした後は、そのウィンドウがあるモニターを自動で撮影します。

## 安全上の注意

- **マウス操作の緊急停止**：マウスを画面の四隅のどこかに勢いよく動かすと、実行中の操作がすぐに中止されます。
- Gemini は閲覧した Web ページやファイルの内容を読み取りますが、その中に悪意のある指示が隠されていることがあります。「すべて自動実行」を使うときは特に注意してください。
- サーバーはこのパソコン上の Chrome 拡張機能からのリクエストだけを受け付けます。一般の Web ページからは呼び出せません。
- 読み取ったファイルやスクリーンショットの内容は Google の Gemini に送信されます。

## フォルダ構成

```
GeminiForge/
├─ start.bat              拡張機能用のサーバーを起動（方法 1）
├─ start_mcp.bat          MCP サーバーを起動（方法 2）
├─ autostart_on.bat       起動時の自動開始を設定
├─ autostart_off.bat      起動時の自動開始を解除
├─ restore.bat            バックアップを一覧表示してファイルを復元
├─ backups/               自動バックアップ（git には含めない）
├─ server/
│  ├─ server.py           すべてのツールの実装。拡張機能用のサーバーも兼ねる
│  ├─ mcp_server.py       MCP サーバー（OAuth 認証 + 確認ウィンドウ）
│  ├─ approve_dialog.py   パソコン上の確認ウィンドウ
│  ├─ backups.py          変更前の自動バックアップと復元
│  └─ requirements.txt
└─ extension/             Chrome 拡張機能
   ├─ manifest.json
   ├─ background.js       リクエストをローカルサーバーへ転送
   ├─ content.js          Gemini ページ上：パネル、ツールコマンドの検出、結果の返送
   └─ prompts/            Gemini 向けのツールの説明。言語ごとに 1 ファイル（編集可）
      └─ zh-TW.md、zh-CN.md、en.md、ja.md、ko.md
```

## よくある質問

- **丸印が赤い**：`start.bat` が起動していないか、閉じられています。
- **ポート 18765 が使用中**：`start.bat` の `set PYTHONIOENCODING` の次の行に `set GF_PORT=別のポート番号` を追加し、`extension/manifest.json` と `extension/background.js` の 18765 も合わせて変更してから、`chrome://extensions` で拡張機能を再読み込みしてください。
- **拡張機能のコード（content.js など）を変更した**：`chrome://extensions` で GeminiForge カードの再読み込み ↻ をクリックし、Gemini を再読み込みしてください。
- **Gemini の更新後に拡張機能が動かない**：Gemini のページ構造が変わったため、`content.js` の入力欄と送信ボタンを探す部分を更新する必要があります。
- **@GeminiForge を確認なしで完全自動にできますか？** 一部だけ可能です：
  - **パソコン上の確認ウィンドウ**：オフにできます。`server/mcp_config.json` の `approval` を `none` に変更してサーバーを再起動してください。
  - **Gemini の Web ページ上の「Allow / Deny」**：オフにできません。これは Google の安全機構で、何かを変更するツール（プログラムの起動、クリック、ファイルの変更）では毎回確認されます。
  - すべてのツールを「読み取り専用」として報告することで、Web の確認をスキップできます：`server/mcp_config.json` で `"web_confirm": "off"` を設定してサーバーを再起動します（既定は `on`）。**自己責任でお使いください**：これは Google の安全設計を回避することになります。Gemini が読んだ Web ページやファイルに悪意のある指示（例：「あるフォルダを削除して」）が隠されていると、確認なしでそのままパソコン上で実行されます。あなたが見ているときだけ使うことをおすすめします。
  - 完全自動に最も近い方法：@GeminiForge を使い `approval` を `none` に設定して、何かを変更するステップごとに Gemini の Web ページで「Allow」を 1 回クリックする。または Chrome 拡張機能（Chat モード）の「すべて自動実行」を使えばクリックは一切不要ですが、あなたが見ているときだけ使うのが望ましいです。
